# OpenDM

An open source Androind control panel for Crestron DM-MD8X8 and DM-MD16X16 switchers. 

## NOTICE

This app in its current state is intended only for hobbist use, and is not suggested for use on active switchers in a corporate or client environent.
All commands are unencrypted and use the telnet protocol.

## Getting Started

### Supported Platforms

* Android 10+

### Download
